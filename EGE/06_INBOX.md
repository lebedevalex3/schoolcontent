# Добавить материал ЕГЭ

1. Оставьте полученные `.tex` и `.sty` в их папке без изменений.
2. Скопируйте подходящий шаблон из [[00_meta/templates/README|шаблонов]].
3. Создайте Markdown-паспорт в `EGE/_catalog/records/`.
4. Добавьте ссылку на существующий README или контекстный файл исходного
   комплекта.
5. Заполните связи с задачей, решением, листом, комплектом или вариантом.

Шаблоны: `ege-task.md`, `ege-solution.md`, `ege-worksheet.md`,
`ege-homework.md`, `ege-pack.md`, `ege-variant.md`, `ege-source.md`.
