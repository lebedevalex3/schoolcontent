# Макеты проверяемых работ ЕГЭ

Здесь хранятся педагогические описания печатных макетов. Они отвечают на
вопросы «сколько места дать ученику» и «как выглядит лист», но не содержат
содержания заданий.

Для первого пилота используется `full-page-solution-v1`: одно задание на
странице A4 с большой рамкой для рукописного решения. QR-код, маркеры краёв и
координаты вырезки добавляет Assessment Core при создании конкретной работы.
