# Презентация к уроку 2

Это Beamer-презентация для живого занятия: одно условие, шаблонный рисунок и
короткая опора на каждом объясняющем слайде. В тренажёре — одно задание и один
рисунок без готового ответа.

Сборка из папки `latex/`:

```bash
mkdir -p ../outputs
xelatex -interaction=nonstopmode -halt-on-error -output-directory=../outputs main.tex
```

Итоговый файл: `../outputs/main.pdf`.

Рисунки подключаются из листа урока 2 и не редактируются в этой презентации.
