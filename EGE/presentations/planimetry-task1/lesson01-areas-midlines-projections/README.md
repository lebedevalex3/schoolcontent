# Презентация к уроку 1

Это Beamer-презентация для живого занятия: один слайд содержит условие,
шаблонный рисунок и короткую опору. В тренажёре на каждом слайде одно задание
и один рисунок, без готового ответа.

Сборка из папки `latex/`:

```bash
mkdir -p ../outputs
xelatex -interaction=nonstopmode -halt-on-error -output-directory=../outputs main.tex
```

Итоговый файл: `../outputs/main.pdf`.

Рисунки подключаются из листа урока 1 и не редактируются в этой презентации.
