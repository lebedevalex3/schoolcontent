# Ященко-2022, 36 вариантов, задание №1

Файлы `variants-*.tex` — неизменённые фрагменты, полученные от автора. В них
нет общей преамбулы, поэтому отдельные PDF собираются скриптом из
`EGE/collections/2022/`.

При сборке из фрагментов берутся условие и ответ. Рисунок для каждого варианта
подключается исключительно из `EGE/tasks/planimetry/TASK-.../latex/figure.tex`:
этот файл — единственный источник истины для TikZ-рисунка.
