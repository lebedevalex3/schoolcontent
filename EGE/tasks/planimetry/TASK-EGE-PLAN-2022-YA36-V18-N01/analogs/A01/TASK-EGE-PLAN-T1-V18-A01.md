# Аналог к варианту 18 — A01

Радиус описанной около \(ABC\) окружности равен \(5\), \(\angle ACB=90^\circ\). Найдите \(AB\).

**Ответ:** (10).

## Решение

По теореме синусов \(AB=2R\sin\angle ACB=2\cdot5=10\).
