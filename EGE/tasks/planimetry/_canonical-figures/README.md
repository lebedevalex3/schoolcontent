# Канонические TikZ-рисунки задания №1 ЕГЭ

Это единственный рабочий источник рисунков для четырёх листов курса
EGE/courses/planimetry-task1 и для созданных презентаций уроков 1--2.
Файлы latex/figures.tex внутри уроков намеренно содержат только \input
этой папки. Поэтому рисунок нельзя исправлять в папке урока: править нужно
ниже, в каноническом файле.

## Как вносить исправление

1. Открыть канонический файл нужного урока.
2. Найти комментарий с номером варианта и именем \fig....
3. Изменить TikZ только здесь.
4. Собрать нужный лист или презентацию. Все материалы, использующие эту
   команду, получат ту же версию рисунка.

Исходные сборники в EGE/sources/2022/Yashchenko36/task01/ не являются
местом для рабочей правки: это архив первичных исходников. Конфигурации,
точки, линии, дуги и отметки фиксированы; в аналогах разрешены только уже
имеющиеся числовые подписи, синхронизированные с условием.
