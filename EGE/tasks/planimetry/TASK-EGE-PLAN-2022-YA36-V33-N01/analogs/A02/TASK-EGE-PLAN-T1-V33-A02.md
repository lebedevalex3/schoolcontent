# Аналог к варианту 33 — A02

\(CA\) касается окружности с центром \(O\), \(CO\) пересекает окружность в \(B\), а дуга \(AB\) внутри угла равна \(40^\circ\). Найдите \(\angle ACO\).

**Ответ:** (50°).

## Решение

\(\,90^\circ-40^\circ=50^\circ\).
