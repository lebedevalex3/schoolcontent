# Аналог к варианту 3 — A02

Около трапеции описана окружность. Периметр трапеции равен \(50\), средняя
линия равна \(14\). Найдите боковую сторону трапеции.

**Ответ:** \(11\).

## Решение

Сумма оснований равна \(28\). Вписанная трапеция равнобедренная, поэтому
каждая боковая сторона равна \((50-28)/2=11\).
