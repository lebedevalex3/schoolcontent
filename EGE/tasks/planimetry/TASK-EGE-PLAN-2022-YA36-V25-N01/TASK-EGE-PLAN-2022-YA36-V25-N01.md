# Прямоугольный треугольник: высота и биссектриса

Один из углов прямоугольного треугольника равен (66^\circ). Найдите угол между
высотой и биссектрисой, проведёнными из вершины прямого угла.

**Ответ:** (21^\circ). PDF собирается общей командой из [[EGE/collections/2022/COLLECTION-EGE-PLAN-2022-YA36-N01|подборки]].
