# Аналог к варианту 25 — A01

Один из углов прямоугольного треугольника равен \(58^\circ\). Найдите угол между высотой и биссектрисой, проведёнными из вершины прямого угла.

**Ответ:** (13°).

## Решение

Искомый угол равен \(\lvert58^\circ-45^\circ\rvert=13^\circ\).
