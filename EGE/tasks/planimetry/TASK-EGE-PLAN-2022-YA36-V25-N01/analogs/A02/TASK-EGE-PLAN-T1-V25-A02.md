# Аналог к варианту 25 — A02

Один из углов прямоугольного треугольника равен \(72^\circ\). Найдите угол между высотой и биссектрисой, проведёнными из вершины прямого угла.

**Ответ:** (27°).

## Решение

\(\lvert72^\circ-45^\circ\rvert=27^\circ\).
