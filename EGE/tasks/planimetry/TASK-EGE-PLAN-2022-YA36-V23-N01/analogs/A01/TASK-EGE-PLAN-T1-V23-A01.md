# Аналог к варианту 23 — A01

Площадь параллелограмма \(ABCD\) равна \(180\). Найдите площадь четырёхугольника, построенного на серединах его сторон.

**Ответ:** (90).

## Решение

Площадь параллелограмма, построенного на серединах сторон, вдвое меньше исходной: \(180/2=90\).
