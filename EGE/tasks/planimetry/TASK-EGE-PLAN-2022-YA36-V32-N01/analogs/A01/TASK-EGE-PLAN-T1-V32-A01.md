# Аналог к варианту 32 — A01

Два угла треугольника равны \(60^\circ\) и \(42^\circ\). Найдите тупой угол между высотами, проведёнными из вершин этих углов.

**Ответ:** (102°).

## Решение

Тупой угол между высотами равен сумме данных углов: \(60^\circ+42^\circ=102^\circ\).
