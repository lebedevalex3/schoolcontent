# Аналог к варианту 22 — A01

В четырёхугольник \(ABCD\) вписана окружность, \(AB=10\), \(BC=7\), \(CD=25\). Найдите четвёртую сторону.

**Ответ:** (28).

## Решение

Для касательного четырёхугольника \(AB+CD=BC+AD\), значит \(AD=10+25-7=28\).
