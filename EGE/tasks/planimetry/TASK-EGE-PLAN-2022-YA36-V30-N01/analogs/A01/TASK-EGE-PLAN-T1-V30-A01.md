# Аналог к варианту 30 — A01

Высота из вершины тупого угла равнобедренной трапеции делит большее основание на отрезки \(14\) и \(11\). Найдите среднюю линию трапеции.

**Ответ:** (14).

## Решение

Средняя линия равна большему из получившихся отрезков, то есть \(14\).
