# Равнобедренная трапеция: радиус описанной окружности

Боковая сторона равнобедренной трапеции равна её меньшему основанию, угол при
основании равен \(60^\circ\), большее основание равно \(28\). Найдите радиус
описанной окружности этой трапеции.

**Ответ:** \(14\).
