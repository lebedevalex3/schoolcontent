# Аналог к варианту 4

Боковая сторона равнобедренной трапеции равна её меньшему основанию, угол при
основании равен \(60^\circ\), большее основание равно \(34\). Найдите радиус
описанной около трапеции окружности.

**Ответ:** \(17\).

## Решение

При угле \(60^\circ\) большее основание вдвое больше меньшего. Следовательно,
меньшее основание равно \(17\), а радиус описанной окружности равен половине
большего основания: \(R=17\).
