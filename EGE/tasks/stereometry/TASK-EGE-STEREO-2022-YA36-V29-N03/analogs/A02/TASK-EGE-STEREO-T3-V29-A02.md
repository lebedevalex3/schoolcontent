# Аналог к варианту 29 — A02

Шар объёмом \(100\) вписан в цилиндр. Найдите объём цилиндра.

**Ответ:** \(150\).

## Решение

Для шара, вписанного в цилиндр, \(V_\text{цилиндра}=\frac32V_\text{шара}\). Получаем \(100\cdot\frac32=150\).
