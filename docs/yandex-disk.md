# Готовые материалы на Яндекс.Диске

Git хранит исходники: LaTeX, Markdown, конфигурацию и небольшие исходные
ресурсы. Готовые PDF, PowerPoint, видео и аудио в Git не попадают: они
публикуются на Яндекс.Диск через WebDAV.

Путь на Диске повторяет путь в репозитории. Например, файл
`school/5grade/01_NaturalNumbers/output/example.pdf` появится на Диске как
`School Content/school/5grade/01_NaturalNumbers/output/example.pdf`.

## Настройка один раз

1. В Яндекс ID откройте **Безопасность → Доступ к вашим данным → Пароли
   приложений** и создайте пароль типа **«Файлы WebDAV»**.
2. Выполните:

   ```bash
   mkdir -p .secrets
   cp config/yandex-disk.netrc.example .secrets/yandex-disk.netrc
   ```

   Затем заполните `.secrets/yandex-disk.netrc`.
3. Впишите в него логин Яндекса и пароль приложения. `.secrets/` исключена из
   Git, поэтому секрет не будет опубликован.

WebDAV-адрес: `https://webdav.yandex.ru`.

## Публикация

Из корня репозитория:

```bash
# Опубликовать все готовые материалы
scripts/publish-yandex-disk.sh

# Опубликовать только одну тему или урок
scripts/publish-yandex-disk.sh school/5grade/01_NaturalNumbers
```

Команда загружает только PDF, PPT/PPTX, видео и аудио, сохраняет структуру
папок и **ничего не удаляет** с Яндекс.Диска. Она сохраняет локальный
манифест с SHA-256-хэшами в `.secrets/yandex-disk-manifest.tsv`: при повторном
запуске неизменившиеся файлы не отправляются в сеть. Изменённый файл с тем же
путём обновляется на Диске.

Если файл удалили или изменили непосредственно на Яндекс.Диске, а локальный
файл не менялся, используйте принудительную повторную загрузку:

```bash
scripts/publish-yandex-disk.sh --force EGE
```

Для уже выгруженного раздела, который ещё не был внесён в манифест, можно
один раз записать текущие хэши без сетевой загрузки. Используйте это только
если уверены, что версии локальных файлов и файлов на Диске совпадают:

```bash
scripts/publish-yandex-disk.sh --adopt-existing EGE
```

Чтобы использовать другое имя корневой папки на Диске:

```bash
YANDEX_DISK_REMOTE_ROOT='SchoolContent-production' scripts/publish-yandex-disk.sh EGE
```

Для доступа к материалам в Finder и офлайн-синхронизации можно дополнительно
установить приложение Яндекс.Диск. Но для этой команды это не требуется.
