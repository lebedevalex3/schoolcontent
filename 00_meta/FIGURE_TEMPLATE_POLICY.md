# Политика шаблонных рисунков

## Основное правило

Проверенные рисунки в LaTeX/TikZ являются **неизменяемыми шаблонами**.
Нейронка не имеет права самостоятельно править их код или визуальное содержание.

Это относится ко всем элементам рисунка: конфигурации и положению объектов,
вершинам, прямым и окружностям, подписям, числовым меткам, дугам углов, отметкам
равенства, штриховке, толщине линий и размещению объектов на странице.

## Производные задачи

Для создания похожей задачи разрешено изменить только текст условия, числовые
данные, вопрос, ответ и методические материалы вокруг задачи. Сам рисунок
остаётся исходным шаблоном, даже когда новые данные не совпадают с числами или
обозначениями на рисунке.

Например, если в новом условии углы стали \(40^\circ\) и \(50^\circ\), нельзя
заменять на рисунке исходные \(10^\circ\) и \(80^\circ\). Рисунок служит
схемой конфигурации, а источником точных данных является текст условия.

## Что может менять только автор

Владелец базы может вручную исправлять рисунок в исходном `.tex`-файле и затем
пересобирать PDF. После такой правки эта версия становится новым эталонным
шаблоном. Нейронка может выполнить такую правку только при явно выраженном
поручении изменить конкретный рисунок.

## Поля паспорта

Для задач со схемой используйте:

```yaml
latex_locked: true
figure_template_locked: true
figure_role: schematic_template
allowed_content_edits: [condition_text, numerical_data, question, answer]
```

Поле `figure_template_locked: true` означает запрет на изменение самого рисунка;
`allowed_content_edits` не даёт разрешения менять TikZ-код.
