# Проверяемые работы: контракт выдачи

`SchoolContent` хранит учебный материал и его педагогическое описание.
`Assessment Core` создаёт из этого описания конкретный PDF для ученика,
принимает фотографии и хранит результаты проверки.

## Что находится рядом с задачей

У задачи, пригодной для выдачи, есть каталог `assessment/`:

- `task.yaml` — формулировки, постоянные идентификаторы заданий и эталонные
  ответы;
- `rubric.yaml` — критерии и баллы;
- `test-cases.yaml` — контрольные педагогические примеры;
- `issuance.yaml` — какие именно наборы заданий разрешено выдавать как работу
  и сколько места для решения требуется каждому заданию.

Исходные LaTeX-файлы, методические заметки, варианты и рабочие листы не
обязаны быть пригодными для автоматической проверки. Они остаются обычными
материалами библиотеки, пока для них не создан `assessment/issuance.yaml`.

## Пакет выдачи

Один элемент `work_packages` в `issuance.yaml` — это педагогически
проверенный рецепт работы. Он содержит только ссылки на `assessment_item_id`,
а не копии условий. Так редактирование условия происходит в одном месте.

В MVP поддерживается `processing: photo-upload-v1`: одно задание занимает
одну страницу A4, фотографируется учеником и проверяется преподавателем.
Поле `answer_space: full_page` означает большую рамку для полного решения.

## Макет страницы

Человеческое описание доступных макетов находится в `EGE/assessment-forms/`.
Макет определяет видимый ученику лист: формат, поля и место для записи.
Assessment Core накладывает технические элементы сам: QR-код, четыре маркера
краёв страницы, номер страницы и координаты вырезки. Поэтому они не
дублируются в учебном контенте и могут меняться без переписывания задач.

## Статусы

- `draft` — материал можно редактировать, но интерфейс выдачи его не покажет;
- `ready` — пакет прошёл проверку контракта и доступен преподавателю;
- `archived` — старые работы сохраняются, но новые экземпляры не выдаются.

После выдачи Assessment Core записывает в манифест идентификаторы задания,
версии рубрик и commit `SchoolContent`. Уже выданный PDF не меняется при
последующих правках контента.
