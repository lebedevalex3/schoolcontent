# Шаблоны записей

Шаблоны создают только Markdown-паспорта и не меняют LaTeX-комплект.

- `ege-task.md` — математическая задача ЕГЭ;
- `ege-solution.md` — решение или метод решения;
- `ege-worksheet.md` — рабочий лист;
- `ege-homework.md` — домашняя работа;
- `ege-pack.md` — готовый комплект;
- `ege-variant.md` — вариант ЕГЭ;
- `ege-source.md` — первоисточник, ещё не разложенный на задачи;
- `school-module.md` — модуль школьного курса;
- `school-section.md` — раздел школьного курса.
