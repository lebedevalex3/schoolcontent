# Система организации контента

## Неприкосновенность LaTeX

Файлы `.tex` и `.sty` — проверенные исходники печатных материалов. Каталог
системы (`_catalog/`), карты и шаблоны работают только как слой описания:
они не изменяют, не перемещают и не переименовывают LaTeX-файлы.

Для уже готового комплекта сначала создаётся Markdown-паспорт со ссылкой на
папку-источник. Только отдельное, явно согласованное решение может менять
сам LaTeX.

Для геометрических и иных задач с рисунками дополнительно действует
[[00_meta/FIGURE_TEMPLATE_POLICY|политика шаблонных рисунков]]. Даже при создании
похожей задачи с другими числами TikZ-схема, подписи и конфигурация остаются
неизменяемыми; редактируется только текстовое содержание задачи.

## Сущности ЕГЭ

| Сущность | Смысл | Пример |
| --- | --- | --- |
| `task` | математическая задача, условие и ответ | логарифмическое неравенство |
| `solution` | один способ или комплект решений задачи | аналитическое решение |
| `worksheet` | маршрут ученика: опоры, практика, контроль | «Готовимся к решению» |
| `homework` | самостоятельное закрепление | домашняя работа к листу |
| `pack` | готовый методический комплект | два листа + решение + ДЗ |
| `exam_variant` | вариант с порядком заданий | вариант 2022 № 1 |
| `source` | неразобранный первоисточник | присланный LaTeX-вариант |

Задача, решение и лист — разные сущности. Поэтому у одной задачи может быть
несколько решений и несколько листов; один лист может тренировать несколько
задач одного типа.

## Сущности школы

Для школьной математики основной объект — `module`: завершённый учебный
маршрут с ученической, учительской, коррекционной, домашней и усложнённой
ветками. Модуль относится к разделу (`section`) и классу.

## Где лежат записи

- `EGE/_catalog/records/` — паспорта задач, листов, решений, комплектов и
  вариантов ЕГЭ;
- `school/_catalog/5grade/` — паспорта актуальных модулей 5-го класса;
- `00_meta/templates/` — шаблоны для новых записей;
- `EGE/00_INDEX.md` и `school/00_INDEX.md` — главные карты базы.

Папки с существующим содержанием остаются источником истины. Поле
`source_dir` в паспорте указывает на их путь, а блок «Исходный комплект»
содержит кликабельные ссылки на README или контекстный файл.

## Как добавить новый материал

1. Сохранить полученный LaTeX-комплект в рабочей папке без правок.
2. Создать паспорт по подходящему шаблону в соответствующем `_catalog/`.
3. Дать стабильный ID: `TASK-...`, `WS-...`, `SOL-...`, `PACK-...` или
   `MODULE-...`.
4. Связать паспорт с задачей и другими паспортами через Obsidian-ссылки.
5. Указать `status`, тему, уровень, год/класс и `latex_locked: true`. Для задачи
   с рисунком также задать `figure_template_locked: true`.
6. Открыть главную карту: материал появится в Dataview-таблице.

Не нужно дублировать условие или переписывать LaTeX в Markdown, если это не
нужно для методической заметки. Достаточно краткого описания, ответа (если он
известен) и связей.
