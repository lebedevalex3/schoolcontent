# Общая LaTeX-дизайн-система школьных листов

Эта папка является единственным каноническим источником общих стилей для
материалов в `school`.

## Файлы

- `school-worksheet-common.sty` — пакеты, шрифты, геометрия, типографика,
  заголовки, команды и семантические блоки;
- `school-worksheet-color.sty` — цветовая тема;
- `school-worksheet-bw.sty` — чёрно-белая тема.

## Подключение

Для стандартной структуры
`school/<grade>/<section>/modules/<module>/Latex`:

```latex
\input{../../../../../common/Latex/school-worksheet-common.sty}
\ifdefined\modulebw
  \input{../../../../../common/Latex/school-worksheet-bw.sty}
\else
  \input{../../../../../common/Latex/school-worksheet-color.sty}
\fi
```

После подключения локальный `module-preamble.tex` может определить
колонтитулы, код модуля и предметные TikZ-команды. Геометрию, базовые шрифты и
семантические блоки локально переопределять не следует.

## Контекст по умолчанию

Общий стиль использует команды:

```latex
\SchoolWorksheetSubject
\SchoolWorksheetGrade
\SchoolWorksheetSection
```

Их можно определить до подключения стиля. Если команды не заданы,
используются нейтральные значения по умолчанию.

## Обратная совместимость

Старые файлы `modules/common/Latex/module-style-*.sty` в эталонном разделе
являются тонкими оболочками. Они не содержат самостоятельной копии стиля и
перенаправляют подключение к этой папке.

Любое общее изменение вносится здесь и проверяется сборкой эталонных модулей
M01–M07.
