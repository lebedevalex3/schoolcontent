# M05. Ломаная и многоугольник

Статус: содержательный комплект реализован на этапе 4.

## Результат

Ученик различает ломаную и многоугольник и правильно называет их элементы.

## Маршрут

- `M05-R` — вершины, звенья, стороны и тип ломаной;
- `M05-H` — чтение и построение новых фигур;
- `M05★` — фигуры с дополнительными внутренними отрезками;
- после устойчивого контроля — M06.

## Комплект

В `Latex/` реализованы роли `student`, `teacher`, `correction`, `extension`,
`homework-student` и `homework-teacher`, каждая в цветной и чёрно-белой
сборке. Рисунки ломаных и многоугольников перенесены в локальный
`figures.tex`.

## Сборка

```bash
./build-pdfs.sh
```

PDF сохраняются в `outputs/`.
