# M07. Точки через равные промежутки

Статус: содержательный комплект реализован на этапе 5.

## Результат

Ученик находит число промежутков, расстояние и неизвестный параметр ряда
равноудалённых точек.

## Маршрут

- `M07-R` — явный подсчёт переходов на коротком ряду;
- `M07-H` — смешанные прямые и обратные задачи;
- `M07★` — чередование объектов и чётность позиции;
- после устойчивого контроля — дальнейший раздел курса.

## Комплект

В `Latex/` реализованы роли `student`, `teacher`, `correction`, `extension`,
`homework-student` и `homework-teacher`, каждая в цветной и чёрно-белой
сборке. Схемы точек, промежутков и чередующихся объектов находятся в
локальном `figures.tex`.

## Сборка

```bash
./build-pdfs.sh
```

PDF сохраняются в `outputs/`.
