# M04. Точки на отрезке

Статус: содержательный комплект реализован на этапе 4.

## Результат

Ученик устанавливает порядок точек и находит длину целого отрезка или его
частей.

## Маршрут

- `M04-R` — порядок точек и отношение целого и частей;
- `M04-H` — вычисления с новыми схемами и единицами;
- `M04★` — несколько допустимых положений точки;
- после устойчивого контроля — дальнейший раздел курса.

## Комплект

В `Latex/` реализованы роли `student`, `teacher`, `correction`, `extension`,
`homework-student` и `homework-teacher`, каждая в цветной и чёрно-белой
сборке. Геометрические схемы перенесены в локальный `figures.tex`.

## Сборка

```bash
./build-pdfs.sh
```

PDF сохраняются в `outputs/`.
