Каталог содержит общий файл преамбулы модулей:

- `module-preamble-base.tex` — подключение канонической школьной
  дизайн-системы и общие команды модулей;

Все содержательные роли M01–M07 реализованы локальными файлами
`content-*.tex`. Временные заглушки этапа 2 удалены после итоговой приёмки.
