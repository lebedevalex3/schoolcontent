# M03. Единицы длины

Статус: содержательный комплект реализован.

## Результат

Ученик переводит длины между основными единицами и объясняет преобразование.

## Планируемый маршрут

- `M03-R` — восстановление соотношений единиц;
- `M03-H` — составные величины и последовательные переходы;
- `M03★` — сравнение способов и выбор удобной единицы;
- после устойчивого контроля — M04 или M07.

## Комплект

В `Latex/` реализованы роли `student`, `teacher`, `correction`, `extension`,
`homework-student` и `homework-teacher`, каждая в цветной и чёрно-белой
сборке. Схема единиц находится в `figures.tex`.

## Сборка

```bash
./build-pdfs.sh
```

PDF сохраняются в `outputs/`.
