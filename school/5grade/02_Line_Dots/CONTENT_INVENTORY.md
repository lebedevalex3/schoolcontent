# Инвентарь содержания `lesson01–lesson05`

Документ фиксирует судьбу существующего содержания при переходе к модулям
M01–M07. Содержательный перенос всех семи модулей выполнен.
Исходные файлы сохраняются без изменений до общей финальной проверки.

## 1. Обозначения ролей

| Роль | Значение |
|---|---|
| `ядро` | обязательный основной маршрут модуля |
| `опора` | разобранный пример, таблица, алгоритм или практика с подсказкой |
| `контроль` | самостоятельная проверка результата |
| `R` | источник коррекционной ветки |
| `H` | домашняя или дополнительная практика |
| `★` | усложнение после устойчивого базового результата |
| `учитель` | диагностика, ответы или методический комментарий |
| `справка` | источник определения или схемы; не отдельная обязательная роль |

Номер существующего задания не обязан сохраняться как номер в новом модуле.
Формулировки и данные можно уточнять, но математический смысл и ответы должны
быть прослеживаемы по этой карте.

## 7. Файлы учителя, справки и рисунков

Для каждого `lessonXX` действуют общие правила переноса.

- `content-student.tex` — источник заданий и последовательности действий.
- `content-teacher.tex` — источник ответов, типичных ошибок и методических
  ограничений; ответы сверяются заново после изменения данных.
- `content-reference.tex` — источник определений и схем, но не отдельная
  обязательная версия нового комплекта.
- `figures.tex` — источник TikZ-команд; каждая команда переносится вместе с
  содержательным блоком, которому она служит.
- `main-*.tex` — не переносятся как архитектура; новые точки сборки создаются
  по школьному контракту.
- локальные `style-*.sty` — не переносятся; новые модули подключают
  `school/common/Latex`.

## 8. Контроль полноты миграции

Перед признанием переноса завершённым необходимо:

1. отметить реализацию каждой строки таблиц выше;
2. сверить все числовые данные и ответы с исходными учительскими файлами;
3. проверить, что каждое сложное задание имеет явно указанную роль;
4. убедиться, что ни один рисунок не используется с изменённым смыслом;
5. проверить отдельные контрольные точки основного маршрута и веток `★`;
6. только после этого принять решение об архивировании `lesson01–lesson05`.

На этапе 1 архивных заданий не назначено: всё существующее содержание либо
входит в основной маршрут, либо используется в `R`, `H`, `★`, учительской или
справочной роли.
