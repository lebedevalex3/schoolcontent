# Самостоятельные работы по блоку «Натуральные числа»

Папка содержит переносимый источник двух итоговых самостоятельных работ.
Она предназначена для передачи в проект, который формирует печатные листы с
полями для ответов, а затем — для проверки учителем или нейросетью.

## Состав

- [`work-A.json`](work-A.json) — работа A для обычного класса;
- [`rubric-A.json`](rubric-A.json) — ответы и критерии работы A;
- [`work-B.json`](work-B.json) — работа B для сильного класса;
- [`rubric-B.json`](rubric-B.json) — ответы и критерии работы B.

В каждом уровне шесть вариантов. Вариант I использует экземпляр `01` каждого
задания, вариант II — `02` и так далее до варианта VI с экземпляром `06`.
Экземпляры `01–02` — оригиналы Ершова, `03–06` — утверждённые аналоги.

## Утверждённый состав

Работа A: `A-01`, `A-03`, `A-04`, `B-02`, `B-05` — 10 основных баллов.

Работа B: `B-01`, `B-03`, `B-04`, `B-05`, `V-02` — 10 основных баллов;
`V-04` со знаком ★ — необязательное задание на 2 бонусных балла. Бонус не
включается в сумму основных баллов.

В задании `B-05` ученик не только перечисляет числа, но и объясняет, почему
других чисел нет. За полноту набора, отсутствие лишних чисел и доказательство
полноты начисляется по одному баллу.

## Контракт данных

Файлы `work-*.json` содержат только выдаваемые ученику формулировки и сведения
для компоновки. Поле `response_contract` подсказывает генератору, какие поля
ответа нужны: одно или два числа, множество чисел, запись словами либо поле
для объяснения.

Файлы `rubric-*.json` содержат ожидаемые ответы, баллы по наблюдаемым критериям,
правила нормализации и диагностические коды ошибок. Порядок чисел в множестве
не учитывается. Оформительские различия в записи числа и регистр текста не
считаются математической ошибкой. Шкала перевода баллов в отметку намеренно не
задана: её должен определять проект проверки отдельно.

Все числа в выдаваемых формулировках и поле `answer_latex` записаны как inline
LaTeX: `\(...\)`. Эти JSON автономны: внешнему проекту не требуется читать
родительский банк задач.

## Печать

Для Assessment Core каталог [`assessment/`](assessment/) содержит sidecar-файлы
`task.yaml`, `rubric.yaml`, `test-cases.yaml` и `issuance.yaml`. В выдаче
доступны две готовые работы с вариантами `I–VI`:

- `G5-NATURAL-NUMBERS-INDEPENDENT-A-V1`;
- `G5-NATURAL-NUMBERS-INDEPENDENT-B-V1`.

Бонусная версия B хранится как отдельный черновой пакет и не попадает в
обычную выдачу, пока Core не научится считать бонус отдельно от основных
10 баллов. Sidecar-файлы воспроизводимо пересобираются командой
`node generate-assessment-sidecars.mjs`; источниками остаются утверждённые
`work-*.json` и `rubric-*.json`.

Старый печатный формат без полей для ответов сохраняется для архива и ручной
печати:

`build-pdf.sh` создаёт чёрно-белые раздаточные PDF в общей папке
`../output/pdf/`:

- `NaturalNumbers-self-study-A.pdf`;
- `NaturalNumbers-self-study-B.pdf`.

В каждом PDF шесть листов A4: один лист соответствует одному варианту. На
каждом листе напечатаны четыре одинаковых экземпляра варианта, разделённые
пунктирными линиями реза. Экземпляр не содержит полей для ответов, имени или
даты и выполняется учеником в тетради.
