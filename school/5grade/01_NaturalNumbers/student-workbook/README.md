# Единый ученический сборник

Папка собирает основной маршрут M01--M07 раздела «Натуральные числа» в два
единых PDF:

- цветную версию;
- чёрно-белую версию для печати.

В сборник входят только основные ученические листы `M01-student` --
`M07-student`. Учительские листы, коррекция `R`, домашняя практика `H` и
усложнение `★` не включаются.

## Сборка

Сначала должны существовать актуальные модульные PDF в `../output/pdf`. При
необходимости их можно пересобрать командой:

```bash
../modules/build-all.sh
```

Затем запустите:

```bash
./build-pdfs.sh
```

Готовые файлы появятся в `output/pdf`:

- `NaturalNumbers-5grade-student-workbook-color.pdf`;
- `NaturalNumbers-5grade-student-workbook-bw.pdf`.

Оба файла имеют одинаковые состав и порядок страниц. Технические пустые
страницы оставляют начало каждого модуля на лицевой стороне при двусторонней
печати.
