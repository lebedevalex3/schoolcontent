# Школьные рабочие листы

Каталог `school` содержит печатные учебные материалы, предназначенные для
работы ученика и учителя в школе.

## Нормативные документы

- [`WORKSHEET_CONTRACT.md`](WORKSHEET_CONTRACT.md) — общий обязательный
  контракт школьного рабочего листа: структура комплекта, учебный маршрут,
  стили, сборка и проверка;
- [`common/Latex/`](common/Latex/) — каноническая LaTeX-дизайн-система для
  цветных и чёрно-белых материалов;
- локальные контракты разделов — предметные термины, возрастные ограничения,
  карта содержания и специальные критерии освоения.

## Эталонная реализация

Эталон общего контракта — комплект
[`5grade/01_NaturalNumbers/modules/`](5grade/01_NaturalNumbers/modules/),
модули M01–M07.

В нём показаны:

- полный учебный маршрут ученика;
- версии ученика и учителя;
- ветви коррекции `R`, домашней практики `H` и усложнения `★`;
- общие цветная и чёрно-белая темы;
- сборка и визуальная проверка полного комплекта.

## Как начинать новый раздел

1. Зафиксировать карту содержания и измеримые результаты.
2. Создать локальный методический контракт раздела.
3. Использовать общий файловый комплект и семантические LaTeX-блоки.
4. Не копировать и не переопределять общие стили без отдельного решения.
5. Собрать цветные и чёрно-белые варианты и выполнить проверку по общему
   контракту.
