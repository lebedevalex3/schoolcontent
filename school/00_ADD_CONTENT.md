# Добавить школьный материал

Для нового модуля 5-го класса:

1. Создайте или получите LaTeX-комплект в рабочей папке, не меняя уже
   проверенные файлы.
2. Создайте паспорт по `school-module.md` в `school/_catalog/5grade/`.
3. Укажите раздел, код модуля, учебный результат и статус.
4. Внутри паспорта поставьте ссылку на README модуля.
5. После сохранения модуль появится в [[school/5grade/00_INDEX|карте 5 класса]].

Для нового раздела используйте `school-section.md`, а затем создайте его
карту по образцу `school/5grade/00_INDEX.md`.
